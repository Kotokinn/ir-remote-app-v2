# Đa ngôn ngữ (i18n)

- Thư viện: `i18next` + `react-i18next`. Khởi tạo ở `src/lib/i18n/index.ts`, bọc app bằng `I18nProvider` trong `app/layout.tsx`.
- Bản gốc là tiếng Anh: `src/lib/i18n/locales/en.json`. `t("khóa")` được TypeScript kiểm tra theo file này, nên gõ sai khóa là lỗi biên dịch.
- Ngôn ngữ = người dùng chọn (Cài đặt → Ngôn ngữ, lưu `smart-home-language`) → ngôn ngữ của thiết bị → English. Khóa thiếu trong một ngôn ngữ tự rơi về English.

## Thêm một ngôn ngữ
1. Tạo `src/lib/i18n/locales/<mã>.json` (vd `fr.json`) với cấu trúc giống `en.json`.
2. Thêm một dòng vào `LANGUAGES` trong `src/lib/i18n/languages.ts` (`code`, `nativeName`, `rtl: true` nếu chữ viết từ phải sang trái).
3. `npm test` — `locales.test.ts` báo khóa thừa/thiếu, sai biến `{{...}}`, thiếu dạng số nhiều.

Số nhiều: dùng hậu tố `_one`, `_other` (và `_few`, `_many`, `_zero`, `_two` nếu ngôn ngữ cần — xem `Intl.PluralRules`). Tiếng Việt chỉ có `_other`. Gọi `t("khóa", { count })`, đừng ghép chuỗi tay.

## Quy tắc khi viết UI mới
- Không viết chuỗi cứng trong JSX/thuộc tính (`aria-label`, `placeholder`, `title`). Thêm khóa vào `en.json` rồi dùng `useTranslation()`.
- Dữ liệu lưu "chữ nào" thay vì chữ (vd `nameKey: TKey`) và dịch lúc vẽ.
- Ngoài React (store, lib) dùng `import { t } from "@/lib/i18n"`.
- Ngày, số, thứ trong tuần, "5 phút trước": dùng `Intl` (`lib/i18n/format.ts`, `formatRelativeTime`), không tự dịch.
- Bố cục hai chiều (RTL): dùng `ms-/me-/ps-/pe-/start/end`, không dùng `ml/mr/pl/pr/left/right`.
- Tên do người dùng đặt (phòng, thiết bị, cảnh) không dịch.

## Lỗi từ server
Server trả `code` (+ `params`) trong lỗi API (danh sách: `services/docs/ERROR_CODES.md`). App dịch bằng `errorMessage(error, fallback)` (`src/lib/i18n/errors.ts`) theo khóa `apiError.<CODE>`; mã chưa có bản dịch thì hiện `message` tiếng Anh của server. Đã áp dụng ở `smart-remote-iot` và `auth-service`; `mqtt-service`, `user-service`, `firebasefcm-service`, `api-gateway` chưa có `code`.

## Chưa dịch
Nội dung notification do server tạo và email OTP vẫn tiếng Anh.
